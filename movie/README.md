# BookMyShow Movie App

A complete movie ticket booking web application built with React.js, simulating the functionality of BookMyShow.

## Features

- 🎬 **Movie Browsing**: Browse movies with filters by genre, language, and search
- 👤 **User Authentication**: Register, login, and profile management
- 🎟️ **Ticket Booking**: Multi-step booking process with seat selection
- 💳 **Secure Payments**: Multiple payment options (Credit/Debit, UPI, Net Banking)
- 📱 **Responsive Design**: Mobile-first responsive design
- 🏪 **Theater Selection**: Choose from multiple theaters with showtimes
- 📊 **User Dashboard**: View booking history and account details
- 🖨️ **E-Tickets**: Digital tickets with print and share options

## Tech Stack

- **Frontend**: React.js 18, React Router DOM 6
- **Styling**: Tailwind CSS 3, Custom CSS
- **Icons**: Lucide React
- **State Management**: React Context API
- **Local Storage**: For persistent data
- **Build Tool**: Vite
